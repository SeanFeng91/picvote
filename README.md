# Vivo Pic Vote

百人级图片 / 视频作品投票系统第一版骨架，基于 Next.js App Router 实现。

## 当前已完成

- 工号 + 口令登录
- 用户首页、上传页、相册页、作品详情页、分享页、我的投票记录
- 每人仅 1 个有效作品，删除后才能重新上传
- 作品自动编号
- 默认 1 票，可通过上下箭头调整票数
- 手机端双列瀑布流相册
- 管理员后台总览、账号配置、作品人工删除
- 大屏作品墙 / 排行榜双模式

## 当前实现方式

- 账号、作品、票数使用 `src/lib/store.ts` 中的内存数据层
- 用户实际上传的文件会落到本地 `public/uploads/`
- D1 表结构已写入 `migrations/0001_init.sql`
- 后续把 `store.ts` 和 `storage.ts` 替换为 D1 / R2 实现即可进入 Cloudflare 真实数据链路

## 演示账号

- 管理员：`90001 / admin123`

## 启动

```bash
npm install
npm run dev
```

默认访问：

- 用户端：`http://127.0.0.1:3000/login`
- 管理端：`http://127.0.0.1:3000/admin/login`
